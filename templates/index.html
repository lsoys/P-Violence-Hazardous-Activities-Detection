About XDVioDet

What is XDVioDet?

XDVioDet is an advanced AI-powered video violence detection system built on deep learning and graph neural networks. It analyzes video content frame-by-frame to identify and classify violent activities with high accuracy.

Technology Stack

  • PyTorch - Deep Learning Framework
  • Graph Convolutional Networks
  • Spatial-Temporal Feature Extraction
  • Flask - Web Application

Key Features

  • Real-time Violence Detection
  • Frame-by-Frame Analysis
  • Interactive Video Player
  • Confidence Scoring
  • Violence Detection Timeline
  • YOLO-Style Detection Boxes

Supported Violence Indicators

Physical Assault Mob Violence Fighting Weapons Threatening Gestures Blood Explosions Hazardous Scenarios
