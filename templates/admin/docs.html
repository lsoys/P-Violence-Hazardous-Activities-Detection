How Live Detection Works

The EdgeSafe AI system utilizes a multi-layered approach to identify hazardous activities in real-time.

  • Visual Analysis: The system processes the video stream at 30 frames per second using YOLOv8 (You Only Look Once) to identify objects like people, weapons, and tools.
  • Motion Analysis: High-speed movement and rapid frame changes are analyzed to detect fighting, panic, or aggressive actions.
  • Environmental Hazards: Specific HSV color range analysis is performed to detect fire and smoke signatures.

How Alerts are Stored

When the system detects a threat with a confidence level exceeding 0.60 (60%), it automatically triggers an evidence capture event.

Saved Evidence

  • High-resolution JPEG frame of the event
  • JSON metadata containing detection scores
  • List of specific objects/hazards identified

Storage Policy

  • Stored in /uploads/violence_events
  • 10-second cooldown between consecutive captures
  • Timestamp-based filenames for easy sorting
